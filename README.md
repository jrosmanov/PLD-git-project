## 🚀 Başlama

### Texnologiyalar
- Node.js (optionalsı)
- Brauzer (Chrome, Firefox, Safari, vəs.)

### Qurulum və Run

```bash
# 1. Repozitoriya klonlayın
git clone <repo-url>
cd PLD-git-project

# 2. Serveri başladın (Python)
python -m http.server 8000

# VƏ YA Node.js istifadə etsəniz:
npx http-server -p 8000
```

3. Brauzerə açın: **http://localhost:8000**
